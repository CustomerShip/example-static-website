About this site

This is a small demonstration of a static website built with nothing but HTML, CSS, and vanilla JavaScript — no frameworks and no build step.

How it is structured

Each page is a standalone HTML file sharing one stylesheet (css/style.css) and a small script (js/shared.js) that highlights the active nav link. Interactive pages load their own script plus a shared storage helper.

Where the data lives

State is stored client-side through js/db.js, a tiny Promise-based wrapper around IndexedDB using a single key/value object store. If IndexedDB is unavailable, it transparently falls back to localStorage. Nothing is sent to a server — everything stays in your browser.

  • counter.total / counter.firstClickTs — all-time click stats
  • colors.last — your last mixed RGB color
  • todo.items — your saved to-do list

The counter stats explained

Session figures live in memory and reset on reload. All-time figures persist in the browser. Clicks per second are computed by dividing the click count by the seconds elapsed since the first click (session start or the first click ever recorded), and they update live once per second.
